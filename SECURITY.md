# Security policy

## Reporting a vulnerability

Please report a security problem in Scrimmage privately, not in a public issue.

PLACEHOLDER: the private reporting channel is not set yet.
The maintainer will add it here before the first release.

Please include what you found, how to reproduce it, and the version or commit you tested.

## How a report is handled

DRAFT, to be confirmed by the maintainer:

- **Response:** a first reply within 5 working days, and an assessment within 15 working days.
- **Supported versions:** Scrimmage has no release yet.
  Until 1.0, only the latest release, and the `main` branch, get security fixes.
- **Disclosure:** a fix is released before details are published.
  Details are published 90 days after the report, or when the fix is released if that is sooner, unless the reporter and the maintainer agree on another date.
